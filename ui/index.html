Step 3 · Council

Convene the council

Seats are (model × persona) pairs. Mock mode runs deterministic heuristic reviewers — no API keys needed; live modes read keys from the server environment.

Models are assigned per seat in the chamber below. Ids may pin a vendor: anthropic:…, openai:…, gemini:…, xai:… — endpoints and the default bench are server configuration (*_BASE_URL, GAGE_DEFAULT_MODELS), so internal gateways work without code changes.


The council

Chamber — who holds which seat

The matrix is the assignment: rows are charters, columns are the models on the bench, and every cell is a seat. Add models to the bench below, then click cells to assign (round-robin: one model per charter) or to seat/vacate pairs (matrix) — or type a model id directly on a seat's row to give that seat its own model. During the run each cell reports live — findings land in the cell the moment that model produces them. Click any cell, any time, to open that seat's full evaluation: charter, scores, findings, and the cross-exam it gave and received. The chairman bar assigns the judge. Ink monogram = contrarian, outlined = genre specialist; the grid locks at convening and mirrors the frozen plan.
